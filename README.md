# Posto ARGB Control — primeira versão

Esta versão é um protótipo funcional da interface Windows/web.

## Abrir
1. Extraia o ZIP.
2. Abra `index.html` no Chrome/Edge.

## O que já funciona
- Interface do controlador ARGB
- Rainbow, cor fixa, respiração, onda e desligado
- Cor, brilho e velocidade
- Presets
- Indicadores de hardware
- Layout responsivo

## Próxima etapa
A interface ainda não envia comandos elétricos para os LEDs. Para isso precisamos identificar a placa-mãe/controladora e implementar o backend Windows correspondente.
